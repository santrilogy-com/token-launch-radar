How the value is worked out

Implied value = TVL × base multiple × growth × maturity × chain spread × TVL slope × level. The base multiple is calibrated per category from the live-token protocols in this same snapshot: the trimmed geometric mean (10% trimmed each tail) of the market-cap-to-TVL ratios of the protocols in that category that already trade, winsorized to the 5th–95th percentiles first (the raw ratios run from 0 to 400×) and then shrunk toward the global centre with k = 3 comparables, so a category with few live comparables is pulled toward the global instead of trusting a thin centre, then clamped to 0.05–0.60. The level factor is fitted from the same live comparables, each priced with itself left out, so the median comparable is priced at its actual market cap. Maturity is a log curve centred at 1.0 for a one-year-old protocol. The TVL slope is fitted from the same live comparables: the market pays less per TVL dollar to bigger protocols. Nothing here is a hard-coded list of names, and a protocol that records a token already is never ranked — it is shown apart, at the market’s own value.
