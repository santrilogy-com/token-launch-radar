How the value is worked out

Implied value = TVL × base multiple × growth × maturity × chain spread. The base multiple is calibrated per category from the live-token protocols in this same snapshot: the median market-cap-to-TVL ratio of the protocols in that category that already trade, clamped to 0.05–0.60. Categories with fewer than three live comparables use the global median. Nothing here is a hard-coded list of names, and a protocol that records a token already is never ranked — it is shown apart, at the market’s own value.
