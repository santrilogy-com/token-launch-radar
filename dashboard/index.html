The walk-forward odds FAIL, and the reason is measured, not guessed: the share of listed protocols that have a token fell from 74.0% (listed before Jul 2024) to 37.7% (listed after), and from 65.8% to 35.6% for the Jan 2025 cut. Every variant fails identically, including TVL-only, so no predictor is the culprit; the intercept fitted on the old mix over-calls tokens in the new mix. The odds on this board are therefore cross-sectional: they rank protocols within this snapshot. They are not a time-to-listing forecast, because the snapshot carries no token-launch dates.

Intervals and bootstrap

Intervals come from the leave-one-out log-residuals: P25–P75 multiplies implied value by ×0.298 to ×4.088, P10–P90 by ×0.056 to ×9.071. Wide, because the typical prediction is about 3.7× off. Split-half coverage: first half trains, second half tests, then swapped: P25–P75 covers 45.3% and 57.8% (target 50%), P10–P90 covers 73.4% and 81.3% (target 80%). Bootstrap, 200 seeded refits: size slope −0.478 (P5 −0.623, P95 −0.333); level factor 1.052 (P5 0.875, P95 1.283). The top-10 rank ranges over the 200 refits are shown in the strip below the board.

How the value is worked out

Implied value = TVL × exp(intercept + size slope × ln(TVL / reference TVL) + category effect) × level factor. The ridge is fitted on the snapshot’s own live-token protocols (128 with a market cap above zero): the size slope is −0.49, so bigger protocols earn less per TVL dollar, and each category effect is shrunk toward zero with penalty λ = 30, so a category with few live comparables is pulled toward the global instead of trusting a thin centre. The level factor (1.04) is fitted leave-one-out from the same comparables, so the median comparable is priced at its actual market cap. Nothing here is a hard-coded list of names, and a protocol that records a token already is never ranked: it is shown apart, at the market’s own value.
